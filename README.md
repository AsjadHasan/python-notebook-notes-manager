# python-notebook-notes-manager
A simple Python OOP project that implements a Notebook class to store, manage, and display multiple notes using instance attributes and class methods.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP)
2. Class and Object
3. Constructor (__init__)
4. Instance Attributes
5. Instance Methods
6. Lists and Mutable Data Structures
7. List append() Method
8. for Loop
9. enumerate() Function
10. String Formatting (f-strings)
11. Encapsulation Basics
12. Docstrings
